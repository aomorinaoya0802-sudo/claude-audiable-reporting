🎚 Claude Code 声の設定

aivis-speech mod の設定です。変更は自動で保存され、次の読み上げから有効です（Claude Code の再起動は不要）。

声

声(話者/スタイル)
質問のときの声
効果音のあと、この声で読む
思考メモの声
要点だけ訳して読む
AivisSpeech Engine に接続できないため、声の一覧を取得できません。
テスト文

オン / オフ

ハイライトの色
読んでいる文の背景
ハイライトのずれ補正
+で遅く / -で早く (ms)
読む長さ
最終回答の先頭から(文末で切る)

読みの辞書

読み間違いを直します。1行に「語=よみ」で書きます(例: 限界飯=げんかいめし)。英単語は、語の途中には当てません。内蔵の辞書(Claude Code / mod / YouTube など)に、ここの内容が上書きで加わります。
読みを確認
エンジンが読む通りのカナ

Claude Code 側の操作

オン / オフ/aivis on /aivis off
読み上げを止める/aivis stop（次のプロンプト送信でも止まる）
テスト/aivis test
設定画面を開く/aivis settings
「間の長さ」は AivisSpeech Engine 側でほぼ反映されません（voice-bridge でも同じ制約があり、波形側で整形していました。この mod は整形していません）。
